# 永齡學習偵探社・互動夥伴完善版

臺灣國小適用的純前端學習遊戲集合。免安裝、無後端、無帳號伺服器、無外部框架，可直接部署到 GitHub Pages。

## 正式入口

- 根目錄 `index.html`：GitHub Pages 預設入口。
- `hub.html`：舊網址相容用的轉址頁，會自動跳到 `index.html`（不再是重複的完整頁面）。
- 所有子模組的大廳連結統一回到 `../index.html`，避免 404。

核心學習內容全部開放，不需要偵探幣解鎖。

## 共用探索系統

- `detective-system.js`：多個個人／小隊檔案、偵探幣、證據、經驗、背包、稱號與每日委託。
- 每次完整完成一館才結算，不以逐題亂點刷幣。
- 答錯不扣幣，會轉成「迷思通緝」，供之後的個人化救援案件使用。
- 商店幣可以買實際可用的排除選項、重新判斷、考點掃描、下一場補給與支線鑰匙。
- `guild/` 是選擇性的聯合案件局，包含封存案件、迷思救援與七館聯合案。
- 瀏覽器可保存多個檔案，也可匯出／匯入 JSON 跨裝置搬移進度。
- 大廳新增「教師總覽」，可查看本機各檔案最近練習、七館進度、近十次平均正確率、常見迷思與夥伴狀態，並匯出 CSV。
- 每日任務、重複練習限制與照顧次數皆依裝置所在地午夜換日，適合臺灣教室使用。

## 週三數學總複習

- `wednesday-review/` 是獨立的姓名分流頁；輸入學生姓名後，從該生 50 題配置抽出 10、12 或 15 題。
- 七位學生各有 50 題可用母題；沒有會阻擋作答的 `pending` 題槽。
- 3-2「圖形（二）」、3-3「用錢（二）」、3-4「時間（二）」、5-2「分數（一）」、6-2「統計圖表（二）・重量（二）」、6-4「小數（一）」、8-2「分數（三）」、9-3「圖形（五）・分數（四）」及 9-4「小數（三）」均依月檢總表建立題型；所有冊別的 `-1` 統一使用該冊算術應用題。
- 編號 `-1` 統一安排該冊難度的算術應用題；編號 `-5` 安排當冊總複習；其他未核回次與 `mixed` 先使用同冊綜合應用題。
- 錯題會在後面第 3～5 題優先插入同技能、不同數字的修復題；每回最多 15 題。
- 基本操作與生活應用題會在每次抽取時重新生成合規數值；概念辨識與找錯訂正保留固定版本，維持診斷與解析的一致性。
- 每位學生的看過題目、錯題權重、錯誤類型與最近 20 次結果保存在本機；下次抽題會優先重現尚未穩定的技能。
- 每週第一次完成會接入偵探幣、證據、寵物材料與每日願望；同週重做仍更新診斷，但不重複領取主要獎勵。

## 偵探夥伴養成

- `pet/` 是主要養成頁；題目任務是取得飼料、偵探幣、布置與進化材料的主要方式。
- 已領養的夥伴會成為全站隨行像素生物：在大廳與各答題館底部自行走動、休息，點擊可摸摸牠，並會依答對、答錯與任務完成做出不同反應。
- 答題頁底部的空白區可用來呼叫夥伴；拖曳線索球後，夥伴會追到放下的位置。不同動物具有不同移動速度，低飽足或低心情時也會主動表達需求。
- 大廳與答題頁可開啟「上課專注模式」，暫時隱藏遊蕩夥伴但不影響任何養成進度。
- `pet/` 房間加入可走動的互動區、食盆、小床與玩具。點地面可指定移動位置；點家具後夥伴會靠近，再由玩家決定是否消耗飼料或玩具，系統不會自動扣除背包用品。
- 九種動物素材都存放於 `assets/pets/`，不依賴外部圖片服務；手機版會縮小活動範圍，並尊重系統的減少動態效果設定。
- 初始可選線索犬、推理貓、跳跳兔、口袋鼠。
- 檔案鴞、墨燈狐、守護熊、整理企鵝、神祕幼龍需透過館別證物、跨館探索或聯合案件解鎖。
- 同一份偵探檔案可收藏多位夥伴並自由切換；每位夥伴各自保存名字、成長階段、親密度、房間及配件。
- 夥伴成長採彈性 2＋2＋3 路線：進化前由孩子親自勾選館別材料；孵化選 2 館、少年期選另外 2 館、成熟期完成剩下 3 館。完整養成仍會接觸七館。
- 任務正確率 85% 以上取得完整進化材料；70～84% 取得半份碎片，兩片會自動合成，降低認真練習卻長期卡關的挫折。
- 幼年、少年與成熟期有不同體型與光效；親密度 3／8／15／25 會依序解鎖召回速度、動物個性動作、答題慶祝與信任光圈。
- 每位已孵化夥伴每天提出一個短願望，完成指定館別或 70% 正確率任務，可取得親密度與牠喜歡的用品。
- 商店提供照顧用品、五種配件與四種房間背景；未收藏布置採每週輪替，已購買內容永久保留。
- 夥伴離線時只會緩慢降低狀態，最低停在安全值；不會因學生一週未登入而死亡或自動生病。
- 舊版單一夥伴存檔會自動搬進新版收藏。
