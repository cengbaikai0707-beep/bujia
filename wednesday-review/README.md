# 週三數學總複習維護說明

正式頁面：`wednesday-review/index.html`

## 為什麼使用姓名分流

七位學生的單元比例不同。姓名分流能直接套用教師指定的補強配置，避免孩子自行選到較簡單、較熟悉但不是目前需要補強的章節。

## 七人題庫槽

每位學生固定 50 個題庫槽，實際練習每次抽 10、12 或 15 題。

## 題目狀態

- `verified`：單元名稱與出題邊界已核定，可正式抽題。
- `provisional`：依安全能力範圍建立，可練習，但結果頁會標示為暫定。
- `pending`：保留給未來尚未建立的題目；目前七位學生均為 0 題。

目前 `3-2`、`3-3`、`3-4`、`5-2`、`6-2`、`6-4`、`8-2`、`9-3`、`9-4` 已依「永齡希望小學月檢卷各階檢測範圍」核定為 `verified`。所有冊別的 `-1`、所有 `-5` 及 `mixed` 題為 `provisional`；七位學生的所有題槽仍可抽取。

## 新增正式單元

1. 在 `UNIT_META` 新增單元名稱與狀態。
2. 新增對應的題目產生器或題目陣列。
3. 將產生器加入 `GENERATORS`。
4. 保留題目欄位：`id`、`student`、`unit`、`topic`、`skill`、`questionType`、`difficulty`、`stem`、`options`、`answer`、`explanation`、`errorCode`、`prerequisite`、`variantGroup`、`status`。
5. 執行題數及答案檢查，確認每位學生仍為 50 題且答案存在於選項中。

## 行為規則

- 七位學生各有 50 題可抽；`-1` 為該冊算術應用題，`-5` 為當冊總複習，`mixed` 使用同冊綜合應用題。
- 基本操作與生活應用題每次抽取時都會依單元限制重新生成數字、答案、選項與解析。
- 概念辨識與找錯訂正題固定，不為了換數字破壞迷思診斷。
- 題目以穩定的 `id` 累積錯題紀錄，以 `variantKey` 區分當次動態數值版本。
- 錯題會優先安排在後面第 3～5 題，以同技能不同題目修復。
- 正常抽題約為 20% 基礎、50% 標準、30% 挑戰；15 題模式通常包含 5 題挑戰題。
- 挑戰題沿用數學館題庫的難度設計：逆推、湊整、兩步驟情境、餘數判讀、總價後找零及變化後比較。
- 題數上限為 15；已達上限時會調整現有同技能題目的順序，不再增加題數。
- 本週第一次完成才結算主要偵探社獎勵；重做仍更新錯題與能力紀錄。
- 學生紀錄使用瀏覽器 `localStorage`，不會傳送姓名或成績到網路。
